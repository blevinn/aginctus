# Aginctus v0.2.0 — working release notes

> **Unpublished development draft, updated 2026-11-09.** Current source reports `0.2.0-dev`; this is not a release candidate, operator acceptance record, tag, or authorization to upgrade a live host. Merge status below means code is present on `main`, not that the complete v0.2 deployment was verified. The [v0.2 release roll-up #173](https://github.com/blevinn/aginctus/issues/173) and [milestone](https://github.com/blevinn/aginctus/milestone/2) govern scope and sign-off.

Aginctus v0.2 is extending the v0.1 single-host NixOS/Incus pilot toward bounded native reconciliation, project-scoped operation, more declarative gateway management and repeatable acceptance. **The end-to-end v0.2 destination remains unverified.**

## Highlights — implementation merged

- **Typed operator CLI and testenv commands.** Cobra now owns the command tree, generated help, argument validation and command-family organization. Testenv worker/bootstrap/sweep entry points are unified under `aginctus-testenv`, with further dedicated package extraction ([#372](https://github.com/blevinn/aginctus/issues/372), [PR #667](https://github.com/blevinn/aginctus/pull/667)).
- **Native Incus reconciliation foundations.** Guarded project, bridge and scoped-instance creation, update, lifecycle and selected CLI workload reconciliation use the Incus Go SDK; negative and disposable real-Incus VM tests cover important authority boundaries. New native **gateway topology intent**, **unsafe-shape rejection** and **immutable OCI image identity resolution** also landed ([PR #679](https://github.com/blevinn/aginctus/pull/679), [#719](https://github.com/blevinn/aginctus/pull/719), [#720](https://github.com/blevinn/aginctus/pull/720), [#721](https://github.com/blevinn/aginctus/pull/721)). These are **not** yet a fully deployed native PostgreSQL/LiteLLM stack or retirement of Compose/Apply.
- **Home Manager operator foundations.** Standalone user installation, nonsecret configuration, read-only Incus authority/state diagnostics and mixed-manager inspection coexist with root-owned NixOS firewall policy. VM coverage now exercises activation, downtime, rollback, owner identity and no-implicit-mutation boundaries. Automatic user reconciliation and safe system-to-user cutover remain gated ([#426](https://github.com/blevinn/aginctus/issues/426), [#443](https://github.com/blevinn/aginctus/issues/443)).
- **Gateway declarations and MCP schema.** Provider plugins, nonsecret catalog/model declarations and Nix settings projection are available. Typed MCP registry/grant/capability schema, effective policy inspection and redacted output have landed; declarations do **not** prove workload-scope enforcement or central MCP routing ([#162](https://github.com/blevinn/aginctus/issues/162), [#496](https://github.com/blevinn/aginctus/issues/496)).
- **Managed Sign in with ChatGPT integration.** All nine implementation slices through [PR #692](https://github.com/blevinn/aginctus/pull/692) have merged: the compiled Aginctus `openai-siwc` provider plugin uses the managed LiteLLM gateway and public OpenAI Responses endpoint, with explicit browser/connected-app consent, protected **LiteLLM-only** credential state, exclusive refresh ownership, bounded login/logout, workload-key route bindings and guarded gateway apply. **This is not LiteLLM's built-in `chatgpt/` provider or a Codex/device-code flow.** Synthetic protocol tests and a documented operator workflow exist; real account, host, restart, consent, billable inference and recovery acceptance still require explicit authorization ([SIWC guide](../gateway-siwc.md), [#187](https://github.com/blevinn/aginctus/issues/187)).
- **Initial configured/accepted/current state contracts.** A provisional three-layer architecture and strict **nonsecret selection-only** manifest with configured identity projection have merged ([PR #702](https://github.com/blevinn/aginctus/pull/702), [#716](https://github.com/blevinn/aginctus/pull/716), [#717](https://github.com/blevinn/aginctus/pull/717)). No full accepted revision, authenticated state service, CAS promotion, read-write CLI workflow or automatic reconciliation is shipped. System/user authority across Incus projects remains a security design gate ([#693](https://github.com/blevinn/aginctus/issues/693), [#704](https://github.com/blevinn/aginctus/issues/704)).
- **Testing and evidence tooling.** A typed Go test/VM catalog, bounded hermetic runner and redacted machine-readable reports replace duplicate Python reporting paths. VM evidence viewing, synthetic full-stack fixtures and opt-in isolated test worker foundations are stronger; local acceptance coverage and real fresh-host evidence remain separate ([#630](https://github.com/blevinn/aginctus/issues/630), [#475](https://github.com/blevinn/aginctus/issues/475)).
- **Faster and more targeted CI.** Core [#712–#715](https://github.com/blevinn/aginctus/pull/715) work adds parallel Go and static lanes, conservative Nix security-contract selection and a fail-closed required PR aggregate, while running full regression on `main`, schedule and explicit dispatch. Ruleset rollout guidance has merged ([#723](https://github.com/blevinn/aginctus/pull/723)); representative elapsed times and administrator/smoke evidence do not yet constitute measured fleet-wide p50/p90 signoff ([#705](https://github.com/blevinn/aginctus/issues/705), [#710](https://github.com/blevinn/aginctus/issues/710)).
- **Reorganized documentation.** The [docs home](../README.md) now navigates operations, architecture, reference, testing, development and history. Current procedures are separated from proposals and old pilot notes; link/navigation checks have expanded. Closeout of the wider docs program still belongs to [#645](https://github.com/blevinn/aginctus/issues/645).

## Compatibility and upgrade guidance (provisional)

The v0.1 baseline supports a trusted **x86_64 NixOS/Incus single-host** deployment. The v0.2 drafts do not establish a production multi-tenant security boundary, unrestricted user Incus authority or support for new platforms. The Home Manager operator runs with the operator's independently provisioned capabilities; the NixOS host still owns firewall, bridges, privileged daemon and storage policy.

**Do not automatically converge or migrate an existing pilot** based on the merged native gateway intent or accepted-state selection manifest. Preserve PostgreSQL, LiteLLM gateway keys and state, Herdr SSH identities, SIWC credential volume, managed volumes, model registrations and images. Migrations require explicit resource inventories, owner/no-adoption checks, backups and tested rollback/resume paths. Ordinary Nix pin rollback does not revert changes already made to runtime data. SIWC private rotating tokens must be recovered through managed authorization, not copied or restored from snapshots ([#198](https://github.com/blevinn/aginctus/issues/198), [#202](https://github.com/blevinn/aginctus/issues/202), [SIWC guide](../gateway-siwc.md)).
